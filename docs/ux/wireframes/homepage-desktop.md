# Homepage Desktop Wireframe (Low-Fidelity)

Viewport target: `>= 1024px`

## State: Default Homepage

```text
+--------------------------------------------------------------------------------------------------+
| [HEADER + PRIMARY NAVIGATION]   Blog / Home / Blog / Tags / About            [Search] [Subscribe]|
+--------------------------------------------------------------------------------------------------+
| [CORE CONTENT]                                                                           | [DISCOVERY / TAGS] |
| [HERO / INTRO]                                                                           | - All topics       |
| Page title / value proposition                                                           | - Design           |
| Short intro paragraph                                                                     | - Writing          |
| Primary CTA: Browse posts                                                                 | - Notes            |
| Secondary CTA: View latest                                                                | - Tutorials        |
|                                                                                          | - Archived series  |
| [POST FEED]                                                                               |                    |
| Featured/latest post card                                                                 | [NAVIGATION AID]   |
| [Card] Title | date | excerpt | Read                                                     | - Jump to top      |
|                                                                                          | - Jump to posts    |
| Post list/grid                                                                            | - Jump to tags     |
| [Card] Title | date | excerpt | Read                                                     |                    |
| [Card] Title | date | excerpt | Read                                                     |                    |
| [Card] Title | date | excerpt | Read                                                     |                    |
|                                                                                          |                    |
| [PAGINATION / LOAD MORE]                                                                  |                    |
| Page 1 of N   [Previous] [Next]   or   [Load more posts]                                  |                    |
+--------------------------------------------------------------------------------------------------+
| [FOOTER] Copyright | Social | RSS | Legal                                                            |
+--------------------------------------------------------------------------------------------------+
```

## Behavior Notes

- The hero introduces the site and routes users into the post feed.
- Discovery stays visible on desktop as a right rail for tag/category scanning.
- Pagination can be rendered as numbered pages or a load-more control, depending on implementation.
- Navigation remains in the header so the homepage is still a clear entry point for the rest of the site.
