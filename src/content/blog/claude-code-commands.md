Claude Code provides a powerful set of slash commands that accelerate common development tasks. These commands provide quick access to specialized functionality without leaving your coding flow.

## Navigation and Search

Quickly move through your codebase and find what you need:

- `/file` - Jump to a specific file by path or search
- `/grep` - Search code using regular expressions
- `/glob` - Find files matching a pattern
- `/history` - View and navigate through recent actions

## Code Understanding

Dig deeper into your code without losing context:

- `/explain` - Get detailed explanations of code sections
- `/diagram` - Generate visual representations of code structure
- `/memory` - Access stored context about the project
- `/doc` - Read documentation files

## Development Tasks

Streamline your workflow with task-oriented commands:

- `/commit` - Stage changes and create commits with meaningful messages
- `/pr` - Create and manage pull requests
- `/fix` - Automatically fix linting errors and common issues
- `/test` - Run tests and analyze results

## Planning and Organization

Structure your work effectively:

- `/plan` - Enter plan mode for complex implementation tasks
- `/todo` - Manage task lists within your session
- `/note` - Create and access session notes
- `/schedule` - Set up recurring tasks and reminders

## Context and Configuration

Control how Claude interacts with your project:

- `/settings` - View and modify Claude Code configuration
- `/clear` - Clear the current conversation context
- `/help` - Access command reference and documentation

## Tips for Effective Use

The most productive developers combine commands strategically. Start with `/plan` for complex features, use `/file` and `/grep` to navigate efficiently, and leverage `/commit` with `/pr` for smooth git workflows. The key is letting the commands handle repetitive work while you focus on problem-solving.
