This is the initial Markdown post for the project scaffold.

## Post Format

Blog posts are written in Markdown with YAML frontmatter. Each post must include these required fields:

- `title`: The human-readable post title
- `publishDate`: Publication date in `YYYY-MM-DD` format
- `slug`: URL-safe unique identifier (lowercase letters, numbers, hyphens)
- `description`: Short plain-text summary for listings and SEO

## Where to Add Posts

Place new post files in the `src/content/blog/` directory. The filename should match the slug for consistency.
